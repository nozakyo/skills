# Code Review

## Instructions

以下の手順でコードをレビュー・修正する。

### 1. ガイドラインの確認

[コーディングルール](./GUIDLINE.md) を参照し、実装が規約に準拠しているか確認する。

### 2. レビュー観点でチェック

[レビュー観点](./REVIEW_PERSPECTIVE_MS.md) に従い、優先度順に確認する。

| 優先度 | 内容 |
|--------|------|
| **must** | 必ず指摘・修正する |
| **imo** | 推奨として指摘する |
| **nits** | 細かい改善提案として伝える |

### 3. 結果の出力

指摘がある場合は以下の形式で報告する。

```
## [優先度] セクション名

- 指摘内容
  - 該当箇所: `コードや行番号`
  - 理由: なぜ問題か
  - 修正案: どう直すか（修正の場合はコードも示す）
```

指摘がない場合は「問題なし」と伝える。
